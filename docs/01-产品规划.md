# 01 · 产品规划

## 1. 产品定位

**「只有猫」（CATSJUST）** —— 一个只属于猫咪的内容分享社区。

- **形态**：类小红书 —— 双列瀑布流首页、图文/短视频笔记、详情页互动；
- **垂直**：全部内容围绕猫咪（猫咪照片、猫咪视频、猫咪日常、猫咪档案、品种科普、猫咪话题）；
- **专业**：提供「猫咪档案」这一差异化功能，让每只猫拥有自己的主页与信息卡（品种、年龄、性格、故事），形成「猫比人红」的内容生态；
- **非商业**：无电商、无广告位、无付费会员，纯粹为展示与分享。

## 2. 目标用户

| 用户角色 | 描述 | 核心诉求 |
|----------|------|----------|
| 铲屎官（发布者） | 想晒自家猫 | 方便发布、获得点赞评论、记录猫咪成长 |
| 云吸猫用户 | 不养猫但爱看 | 刷到高质量猫内容、收藏、关注喜欢的猫/博主 |
| 猫咪博主/KOL | 有内容生产能力 | 建立个人主页、沉淀粉丝、形成话题影响力 |
| 管理员（后台） | 平台运营 | 审核内容、管理用户、查看数据、处理举报 |

## 3. 功能清单

### 3.1 前台（用户端）

#### 账号体系
- [ ] 注册 / 登录（邮箱 + 验证码；P1 先支持邮箱密码，后续可加第三方登录）
- [ ] JWT 会话保持、退出登录、修改密码、找回密码
- [ ] 个人资料：昵称、头像、简介、封面图

#### 内容发布
- [ ] 发布图文笔记：多图上传、拖动排序、封面选择、文字描述
- [ ] 发布视频笔记：单视频上传、封面帧选择、标题描述
- [ ] 发布时可为猫咪选择/创建「猫咪档案」，打标签（话题、品种）
- [ ] 草稿箱（P2）、编辑/删除自己的笔记（P2）

#### 信息流（首页）
- [ ] 双列瀑布流布局，懒加载 + 下拉刷新
- [ ] Tab：**推荐** / **关注**（P2）/ **最新**
- [ ] 卡片展示：封面图、标题、作者昵称、点赞数（P1 从简：推荐 = 最新排序）

#### 内容详情页
- [ ] 图片轮播 / 视频播放
- [ ] 正文、发布者信息、关联猫咪档案、标签
- [ ] **点赞**（可取消）、**收藏**（可取消）、**评论**
- [ ] 评论：一级 + 二级（楼中楼）评论，评论点赞（P2）
- [ ] 分享：复制链接（P2）

#### 用户主页
- [ ] 头像、昵称、简介、关注数/粉丝数
- [ ] Tab：作品 / 收藏（P2）/ 喜欢（P2）
- [ ] 关注 / 取关按钮（P2）

#### 猫咪档案（垂直差异化）
- [ ] 猫咪主页：头像、名字、品种、性别、生日/年龄、性格标签、简介
- [ ] 该猫咪下的所有笔记聚合页
- [ ] 按品种浏览猫咪（P2）

#### 话题与标签
- [ ] 话题页：话题封面、简介、话题下内容流
- [ ] 热门话题榜（P2）

#### 搜索（P2）
- [ ] 搜索内容 / 用户 / 话题 / 猫咪 / 品种

#### 通知中心（P2）
- [ ] 收到点赞、评论、关注、系统通知；未读数角标；WebSocket 实时推送

### 3.2 后台（管理端）

| 模块 | 功能 |
|------|------|
| **仪表盘** | 数据概览：注册用户数、日活、发布量、互动量、待审内容数、趋势图 |
| **内容审核** | 待审列表 / 已审列表；图文、视频审核；通过 / 驳回（附原因）；批量操作 |
| **用户管理** | 用户列表、详情、封禁 / 解封、重置状态、角色管理 |
| **举报处理** | 举报工单列表、处理（删除内容 / 封禁用户 / 驳回举报） |
| **内容管理** | 已发布内容检索、下架、删除 |
| **话题与品种管理** | 话题创建 / 编辑 / 置顶 / 下架；品种词典维护 |
| **系统设置** | 公告管理、服务协议、敏感词库、审核规则配置 |
| **数据统计** | 发布趋势、热门内容、活跃用户、品类分布（P2） |

## 4. 非功能需求

| 类别 | 要求 |
|------|------|
| 性能 | 首页首屏 < 2s；瀑布流滚动流畅；图片懒加载；视频可拖动播放 |
| 安全 | 密码加密存储（bcrypt）；JWT 鉴权；防 XSS（富文本转义）；上传文件类型/大小校验；接口限流防刷 |
| 合规 | 内容审核机制、举报通道、用户协议与隐私政策、未成年内容规避 |
| 兼容 | 桌面 + 移动端响应式；主流浏览器（Chrome / Edge / Safari / Firefox） |
| 可扩展 | 数据结构为多语言预留（原文 + 翻译缓存字段）；存储层抽象便于切换云服务 |
| 数据 | 图片/视频走对象存储 + CDN；数据库定期备份 |

## 5. 差异化亮点（对内对外宣传点）

1. **猫咪档案**：每只猫都有自己的主页，内容按「猫」聚合，是小红书做不到的垂直深度；
2. **纯展示无商业**：干净、无广告的浏览体验；
3. **全球同内容多语言**（P3）：同一篇内容，各国用户看到各自语言，形成真正的全球猫社区。

## 6. 反例清单（不做）

- ❌ 不做电商 / 广告 / 付费；
- ❌ 不做非猫咪内容（不开放泛生活类目）；
- ❌ P1 不做即时通讯 IM；
- ❌ P1 不做推荐算法（先用时间/热度排序）；
- ❌ 不做复杂权限体系（仅普通用户 / 管理员两级，P2 细化）。
