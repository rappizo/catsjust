## 技术要点备忘
- 迁移脚本：`node scripts/db-setup.mjs`（自动发现 supabase/migrations/*.sql，每个迁移独立事务）
- 单独应用迁移：直接编辑后用 db-setup 即可；已有结构会幂等跳过
- i18n 新增词条后：`node scripts/supplement-dictionaries.mjs`（自动补翻 10 种语言）
- 校验词典：`node scripts/verify-dictionaries.mjs`
- 注意：不要并行跑词典生成；不要用 PowerShell 读写含中文的 UTF-8 文件
- 通知实时性：当前为落库 + 刷新拉取；WebSocket 实时推送后置（P3）
- 角色：admin（超管）/ moderator（审核员）/ user；后台登录走 env 的 ADMIN_USERNAME/ADMIN_PASSWORD

## 换电脑后启动步骤
1. `git clone git@github.com:rappizo/catsjust.git`

3. `npm install`
4. `npm run dev`（本地）或 `vercel --prod --yes`（部署）
